============================================================
📸 HOW TO ADD AMU'S REAL PHOTOGRAPHS TO THE WEBSITE
============================================================

1. Place Amu's solo photographs right here in this folder:
   - `amu-hero.jpg`  -> Her best portrait for the Hero section
   - `amu-1.jpg`     -> Gallery Photo 1 (e.g. Favorite Smile)
   - `amu-2.jpg`     -> Gallery Photo 2 (e.g. Main Character Vibe)
   - `amu-3.jpg`     -> Gallery Photo 3 (e.g. Golden Hour Glow)
   - `amu-4.jpg`     -> Gallery Photo 4 (e.g. Candid Laugh)
   - `amu-5.jpg`     -> Gallery Photo 5 (e.g. Elegance & Poise)
   - `amu-6.jpg`     -> Gallery Photo 6 (e.g. One of a Kind)

2. Note on image formats:
   - JPG, PNG, or WebP formats are supported.
   - If your images have different file names (e.g. `amu-sunset.jpg`),
     simply open `src/data/birthdayConfig.js` and change the `src` paths!

3. Fallback protection:
   - If you haven't placed an image yet, the website automatically
     displays high-resolution aesthetic placeholders so nothing looks broken!
